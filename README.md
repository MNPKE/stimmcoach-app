# Vocatief Stimmcoach – App

Installierbare Web-App zum Lernen der eigenen Stimme: Noten mit Mitlese-Cursor, Klavierklang, Mixer, Lernplan, Tonhöhen- und Latenzmessung.

**Hier liegen keine Noten.** Stücke kommen als Paket (`.vsc`) aus der Werkstatt und werden in der App über „Datei auswählen“ geöffnet. Sie bleiben am Gerät, ebenso Lernstand und Aufnahmen. Die App lädt nichts von fremden Servern (Content-Security-Policy: nur eigener Ursprung).

## Installieren
- **Android / Windows / macOS / Linux (Chrome, Edge):** Seite öffnen → „App installieren“ (Knopf oben oder im Browser-Menü).
- **iPhone / iPad (Safari):** Teilen → „Zum Home-Bildschirm“.
